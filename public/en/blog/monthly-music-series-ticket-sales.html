Monthly music or stand-up series: how to sell each date

By SOMOS DER · October 29, 2026 · 5 min read

A series with a fixed date every month lives on the audience that comes back. That changes how you should load the dates, when to open each sale and what to do with the buyers from the previous date. This guide puts it in order, from loading the event to the presale for regulars.

A note before you start: ENTRÁ is an Argentine ticketing platform. It sells tickets for events held in Argentina, priced in Argentine pesos (ARS). What this guide says applies to most events; when it describes how ENTRÁ works, it means in Argentina.

One event per date

The temptation is to load the whole series as a single event. For a monthly series the opposite works better: one event per date. The reasons:

  • Each date has its own page, with its lineup, flyer and description. A series audience comes back for who is playing or performing that night.
  • Each date has its own capacity, which is the room's, and one date's sales don't mix with another's.
  • You see how each date sells separately in the dashboard, and you can compare.
  • If a date is moved or called off, you change or cancel it without touching the others.

If you also want to sell a pass for every date, that is something else: at ENTRÁ it is set up as a multi-day event with a single QR valid once per day. But for a series that lives on single-date tickets, one event per date is the tidiest.

A fixed date, always the same

What makes a series work is that people have it built in: "the first Friday of every month". For that to happen:

  • Same day, same venue, same time. Every change has to be explained, and every explanation loses people.
  • The same series name in the title, plus what changes: "Tuesday Jazz Series: guest of the month".
  • Open sales for the next date before the current one ends, or the day after. The moment the audience is happiest is walking out of the show.

Those who come back are your base

In a series, the repeat audience is worth more than any campaign. The tool to look after it is your buyer list: at ENTRÁ you export it from the dashboard, and it is yours. With it:

  • You announce the next date to people who already came, before social media.
  • You see who comes back, by cross-checking the lists from different dates.
  • You give regulars something the rest don't get: hearing first, paying less or having a guaranteed spot.

How to use that list without burning it is in how to use your buyer list for the next date.

A presale for regulars with a code

The simplest way to reward people who come back is a discount code just for them. At ENTRÁ, when you create a code from the dashboard, you set the discount, how many times it can be used and until when it is valid. For a series:

  • One code per date, sent only to your buyer list, valid for a few days before you announce on social media. That makes it a real presale, not a permanent discount.
  • With a usage limit, if you don't want half the room getting in at a discount.
  • Check how many times it was used: the dashboard shows each code's usage. It is a clue to how responsive your base is.

Codes get forwarded, so think of it as "a presale for those who hear first" rather than something exclusive. The rest about discounts is in discount codes for an event.

The door at a series

  • The same person at the door every month, if possible. They recognize the regulars and the mood of the night starts there.
  • Each QR is valid only once, and only for that date: a ticket from another month won't get past this date's scanner.
  • If someone can't find the email, they are looked up by last name, ID number (DNI) or email from the scanner.
  • The artist's guests: load them as complimentary tickets from the dashboard, with name and reason, so they don't mix with sales.

Frequently asked questions

Do I load the series as one event or as several?

For a monthly series, one event per date works better. Each date has its own page, capacity and sales, and if one is moved or called off you don't touch the others. If you want to sell a pass, it is set up separately as a multi-day event.

How do I run a presale only for people who already came?

Export your buyer list from the dashboard and send them a discount code before announcing on social media. When you create the code you set the discount, the usage limit and until when it is valid.

Is a ticket for one date valid for another?

No. Each date is a different event and each QR is valid for the event it was bought for, only once. If a date is rescheduled, the ticket stays valid for the new date of that same event.
