Access control without internet: what happens if the signal drops at the door

By SOMOS DER · October 29, 2026 · 6 min read

A basement, a warehouse with thick walls, a venue on the outskirts of town or simply five hundred people with their phones out at the same time: the signal drops right when the line forms. If your access control depends on the internet, the door stops. Here is what the ENTRÁ scanner does when there is no connection, what its real limit is and what backup plan is worth bringing anyway.

A note before you start: ENTRÁ is an Argentine ticketing platform. It sells tickets for events held in Argentina, priced in Argentine pesos (ARS). What this guide says applies to most events; when it describes how ENTRÁ works, it means in Argentina.

What the scanner does when the internet drops

The ENTRÁ scanner keeps validating offline. It works like this:

  • It validates against what it already downloaded. When you pick the event while connected, the phone stores the tickets in its memory. With no signal, each QR is looked up there.
  • It marks the ticket as used instantly. The entry message appears without waiting for the server, and if someone scans the same QR again on that phone, it shows "DENEGADO · YA UTILIZADO" (denied, already used).
  • It stores every entry on the phone, including rejected attempts, and syncs them automatically when the connection comes back. You don't have to do anything.
  • The search by person also uses the downloaded data: if someone arrives without their QR, you look them up by last name, ID number (DNI) or email and validate from there.

While there is no network, a yellow banner appears at the top of the scanner warning that there is no connection and that you are still validating with the data already loaded. That way whoever is at the door knows which mode they are working in.

The limit you need to know: several check-in points at once

This is the important part, and the banner itself says it: while there is no internet, each phone only knows the entries it scanned itself. With a single door nothing changes. But if you have two check-in points working at the same time and both lose signal, the same ticket (for example, a shared screenshot) could get through once at each point, because the two phones cannot talk to each other.

Preventing that without a network is not possible. What ENTRÁ does is keep the evidence:

  • Each phone has a check-in point name that you enter at the top of the scanner ("Puerta 1", "VIP", "Prensa").
  • Each entry is signed with that point.
  • When it reconnects, the event dashboard flags which tickets got in twice and through which points.

In practice: if you know the venue has poor signal, the safest setup is a single line per phone for each ticket type, or keeping at least one of the check-in points connected. For more on duplicates, see how to stop fake and duplicate tickets at the door.

Before opening the door: what has to happen while you have signal

Since the scanner works with what it already downloaded, some things are worth doing while you still have internet:

  • Open the scanner and pick the event on every phone going to the door, while connected. That is when the tickets are loaded.
  • Give each check-in point a name, so the log says where each person came in.
  • Test a QR on each phone before people arrive.
  • Keep late sales in mind. A phone without signal does not learn about what was sold or refunded after its last connection. If you keep selling during the event, that is one more reason to have a check-in point with data.

The rest of the door setup (staff, lines, times) is in access control on the day of the event.

The practical backup plan

Offline mode covers the network going down. It does not cover a dead battery, a broken screen or someone logging out by accident. For that, bring this:

  • The attendee list as a CSV. From the event dashboard you export the list: it includes name, email, ID number, phone, ticket type, origin (purchase or complimentary), ticket code and check-in status. Download it before you leave and keep it on a phone or a computer, or print it. If everything else fails, you find the person by name or ID number and cross them off by hand. Later, with signal, you validate those tickets from the search by person so the log is complete.
  • Mobile data from another carrier. If the venue network or your carrier goes down, a phone on another line can share its connection with the rest. Sometimes stepping out of the most crowded area is enough to get signal back and sync.
  • More than one phone. A spare one with the scanner already open and the event selected, charged to 100%. And a charger or power bank per check-in point.
  • Someone who knows how to use the search. The "my QR didn't arrive" or "I deleted it" line moves fast if one person searches by last name or ID number while the rest scan.

Frequently asked questions

Does the ENTRÁ scanner work without internet?

Yes. The scanner keeps validating with the event data the phone had already downloaded, marks each ticket as used on the spot and stores the entries on the phone. When the connection comes back, everything syncs automatically with the dashboard.

Can the same ticket get in twice if there is no signal?

On the same phone, no: the second scan sees it as used even without internet. With two check-in points working at once offline, yes, it can happen, because each phone only knows what it scanned itself. When they reconnect, the event dashboard shows which tickets got in twice and through which point.

How do I know the scanner is working offline?

A yellow banner appears at the top of the scanner saying there is no connection and that you are still validating with the data already loaded. The same banner explains the limit of multiple check-in points and shows the name of that phone's check-in point.

What backup plan should I have at the door?

The attendee list exported as a CSV from the dashboard before you leave, a second phone with the scanner open and mobile data from another carrier to share a connection. With that, even if a phone or the network fails, the door keeps working.

A door that keeps moving if the signal drops

With ENTRÁ the scanner validates offline, each QR is good for one use only and every entry is signed with its check-in point. Creating the account and loading the event costs nothing.
