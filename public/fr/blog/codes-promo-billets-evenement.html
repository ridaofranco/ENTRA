Codes promo pour un événement : les utiliser sans brader la vente

Par SOMOS DER · 29 octobre 2026 · 6 min de lecture

Un code de réduction bien utilisé fait vendre des billets qui ne se seraient pas vendus. Mal utilisé, il baisse le prix pour des gens qui auraient payé plein tarif de toute façon. La différence ne tient pas au pourcentage mais à trois choses : à qui vous le donnez, combien de fois on peut l’utiliser et jusqu’à quand il vaut. Voici comment y réfléchir et ce qu’ENTRÁ vous permet de régler.

Avant de commencer : ENTRÁ est une billetterie en ligne argentine. Elle vend des billets pour des événements organisés en Argentine, en pesos argentins (ARS). Les conseils de ce guide valent partout ; quand il décrit le fonctionnement d’ENTRÁ, il parle de l’Argentine.

D’abord : à quoi sert la réduction

Avant d’inventer un code, répondez à une question : à qui baissez-vous le prix, et pourquoi ? Sans réponse, la réduction finit entre les mains de ceux qui allaient acheter. Les usages qui ont du sens sont peu nombreux :

  • Récompenser un groupe précis. Votre liste d’abonnés, ceux qui sont venus à la date précédente, les membres d’un club, les élèves d’un atelier.
  • Débloquer un palier qui ne démarre pas. Un code court dans le temps pour pousser les premiers jours de vente.
  • Donner quelque chose à ceux qui font la promotion. Un code propre à chaque groupe de l’affiche ou à chaque personne qui fait circuler l’événement, pour que chacun ait quelque chose à proposer.

Si ce que vous voulez, c’est que tout le monde paie moins au début, ce n’est pas un code : c’est un palier moins cher. Pour construire prix et paliers, voyez fixer le prix des billets.

Ce qu’ENTRÁ vous permet de régler

Les codes se créent dans l’onglet Descuentos (réductions) du tableau de bord de l’événement. Chaque code a :

  • Le texte du code. Il est enregistré en majuscules et ne peut pas se répéter dans le même événement. Il ne vaut que pour cet événement : il ne sert pas pour un autre.
  • Le type : pourcentage ou montant fixe en pesos. Dans les deux cas, la réduction s’applique sur le sous-total de l’achat entier, pas par billet, et ne peut jamais le faire passer sous zéro.
  • Une limite d’utilisations, facultative. Si vous la laissez vide, le code n’a pas de plafond.
  • Une date d’expiration, facultative. Si vous la laissez vide, le code vaut tant qu’il est actif.

Une fois créé, dans la liste des codes, vous pouvez le mettre en pause et le réactiver, ou le supprimer. Chaque code affiche son statut (actif, en pause, expiré ou épuisé) et combien de fois il a été utilisé par rapport à son plafond. Un code ne se modifie pas : si vous vous êtes trompé de valeur, vous le supprimez et en créez un autre.

Un détail qui compte : pour les événements gratuits, les codes ne s’appliquent pas, puisqu’il n’y a rien à réduire.

Les trois garde-fous qui évitent de brader la vente

1. Un plafond d’utilisations

Un code sans plafond qui fuit dans un grand groupe finit par vendre tout l’événement à prix réduit. Mettez toujours une limite. Tenez compte de la façon dont ENTRÁ compte :

  • Il compte des achats, pas des billets. Si une personne utilise le code et prend quatre billets, c’est une utilisation. Si votre idée est « dix billets à prix réduit », un plafond de dix peut finir par représenter bien plus de dix billets.
  • L’utilisation est comptée quand la personne commence le paiement, pas quand elle le termine. Si quelqu’un commence l’achat et l’abandonne, cette utilisation est déjà comptée. Gardez un peu de marge.

2. Montant fixe ou pourcentage

Comme la réduction porte sur le total de l’achat, le montant fixe s’applique une seule fois par opération, qu’on achète un billet ou six. Le pourcentage grandit avec l’achat : plus il y a de billets, plus la réduction est grande. Si vous voulez récompenser les groupes qui achètent ensemble, le pourcentage convient. Si vous voulez limiter ce que vous offrez par personne, le montant fixe est plus propre.

3. L’expiration

Un code valable jusqu’au jour de l’événement concurrence votre propre vente à plein tarif. Donnez-lui une date. Attention à la façon de la saisir : le champ ne demande que le jour, et le code cesse de valoir au début de ce jour, pas à la fin. Prenez la date comme le premier jour où il ne vaut plus : si vous voulez qu’il serve jusqu’au vendredi inclus, mettez samedi.

Si quelque chose vous échappe avant l’heure (le code est apparu dans un groupe où il ne devait pas être), n’attendez pas l’expiration : mettez-le en pause depuis la liste, et c’est réglé.

Le code ne peut pas être forcé

L’acheteur saisit le code au paiement et voit la réduction appliquée. Mais ce n’est pas l’écran de l’acheteur qui fixe le prix. Au moment où le paiement est créé, le serveur d’ENTRÁ recherche à nouveau le code dans cet événement et vérifie qu’il est actif, qu’il n’a pas expiré et qu’il n’a pas atteint son plafond. Si l’une de ces conditions échoue, l’achat se fait au prix normal. En plus, la réduction est enregistrée dans la commande, avec le code utilisé.

Comment savoir quel code a vendu

Le moyen direct, c’est la colonne des utilisations de chaque code dans le tableau de bord. D’où l’intérêt d’un code différent par groupe ou par personne qui fait la promotion : « GROUPE1 », « GROUPE2 », « MEMBRES ». À la fin de la vente, vous savez qui a fait vendre des billets et qui non, et ça sert à décider avec qui recommencer.

Cela dit, si tout ce que vous voulez, c’est mesurer d’où viennent les ventes, un code est une façon coûteuse de le faire : pour savoir quel canal a marché, vous baissez le prix pour chaque acheteur. ENTRÁ enregistre d’où vient chaque vente. Si vous partagez le lien de l’événement avec des paramètres utm (par exemple utm_source avec le réseau et utm_campaign avec le nom de l’action), la commande l’enregistre : le tableau de bord l’affiche dans le bloc d’où sont venues les ventes et l’export des ventes comprend les colonnes origine et campagne. Vous mesurez sans rien offrir. Plus de détails dans promouvoir un événement et mesurer les ventes.

La règle pratique : un code pour récompenser, un lien avec utm pour mesurer. Et si ce que vous voulez donner, c’est le billet entier, ce n’est pas une réduction de cent pour cent mais une invitation, qui s’émet à part depuis le tableau de bord.

Questions fréquentes

Quels types de réduction puis-je créer sur ENTRÁ ?

Deux : un pourcentage ou un montant fixe en pesos. Les deux s’appliquent sur le sous-total de l’achat entier, pas sur chaque billet, et ne peuvent jamais faire passer le sous-total sous zéro. Chaque code appartient à un événement et se crée depuis l’onglet Descuentos du tableau de bord.

Le plafond d’utilisations compte-t-il des billets ou des achats ?

Il compte des achats. Si quelqu’un utilise le code et prend quatre billets dans la même opération, c’est une utilisation. En plus, l’utilisation est comptée quand la personne commence le paiement : mieux vaut garder un peu de marge dans le plafond.

Peut-on utiliser un code expiré ou épuisé si on le connaît ?

Non. Le serveur d’ENTRÁ vérifie à nouveau le code au moment de créer le paiement : s’il est en pause, expiré ou a atteint son plafond, l’achat est facturé au prix normal. Ça ne dépend pas de ce qu’affiche le navigateur de l’acheteur.

Comment savoir quel code m’a apporté le plus de ventes ?

Dans la liste des codes du tableau de bord, chacun indique combien de fois il a été utilisé par rapport à son plafond. Si vous voulez mesurer les canaux sans offrir d’argent, partagez le lien de l’événement avec des paramètres utm : l’export des ventes comprend les colonnes origine et campagne.

Sur ENTRÁ, vous créez des codes en pourcentage ou en montant fixe, avec nombre d’utilisations et date d’expiration, et vous les mettez en pause quand vous voulez. Pour un événement en Argentine, écrivez-nous.
